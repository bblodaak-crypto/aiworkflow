# Эталон стиля

- `style.png` — **единственный** эталон стиля игры. Без него `tools/art/gen.py` не генерирует. Это может быть сгенерированная и одобренная пользователем сцена игры, концепт-арт или скриншот-ориентир (если используется чужая работа — только как приватный ориентир стиля).
- `scale_figure.png` (необязательно) — кадр героя 512 × 512 с опорой (256, 480) и ростом около 400 px. Его `tools/slice_props.gd` ставит слева на контрольный лист для сравнения роста; без него рисуется серый силуэт того же роста.

Замена эталона — решение пользователя: после неё прежние наборы могут перестать совпадать по стилю.
