# Каталог ассетов

Собирается `make catalog` (`tools/asset_catalog.gd`), вручную не править; `make check` падает, если файл устарел. Размеры — в игровых единицах (4 px картинки = 1 ед.; рост героя — 100 ед.), по картинке без прозрачного поля.

Вид объекта: **стоящий** — в общем слое с персонажами, сортируется по y; **наземный** — под персонажами (SPRITE_SPEC, «Окружение»). `lift` — подъём картинки над опорой, ед. (жерди забора висят на столбах).
