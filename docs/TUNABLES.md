# Рабочие значения

Решения, которые легко заменить: числа и правила, принятые как рабочие, но не утверждённые окончательно. Сюда записывается каждое такое решение (см. AGENTS.md, «Решения пользователя»): новое — строкой таблицы, изменённое — правкой строки. Читать, когда задача касается баланса, данных в `data/` или поведения из таблицы.

В «Что» — откуда решение (раздел `concept.md` со статусом «Открыто» / «Рекомендация», шаг roadmap); в «Где» — файл или класс, где значение меняется. Решение пользователя — с датой.

| Что | Сейчас | Где |
| --- | --- | --- |
| Проверка ассетов (шаблон, SPRITE_SPEC — черновик) | объект окружения: прозрачное поле 8 px со всех сторон, допуск 1 px; опора — середина нижнего края: левое и правое поле расходятся не больше 2 px, нижнее — 8 ± 1. Лист кадров: ширина кратна 512, высота 512, JSON с `frame_count` = ширина / 512, `frame_size` [512, 512], `pivot` [128…256, 480]. Ореол: среди пикселей края с альфой 0,1–0,9 (если их не меньше 20) почти белых (`ink` < 0,08) не больше 15 %. Кадры: разброс роста и x опоры кадров зацикленной анимации — не больше 6 % и 8 % медианного роста, иначе предупреждение `slice_sheet.gd`. Плитка земли: непрозрачная, шов (`SEAM_MAX`) — не больше 0,03 | `tools/asset_rules.gd`, `tools/slice_sheet.gd` |
| Сборка кусков локации (шаблон) | опоры двух объектов куска не ближе 40 ед. (`MIN_GAP`); опора — внутри квадрата куска; сторона по умолчанию 1200 | `tools/chunk_layout.gd` |
