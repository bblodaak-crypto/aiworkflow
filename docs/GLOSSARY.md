# Глоссарий

Единые термины для документов и кода. Имя в коде — то, как понятие называется в классах, файлах и данных. Добавлять сюда термин при первом появлении в коде; при расхождении с `concept.md` приоритет у `concept.md`, а глоссарий исправляется.

| Термин | Имя в коде | Значение |
| --- | --- | --- |
| Набор ассетов | `design/concepts/<набор>/` | Партия сгенерированных картинок одной темы с промптами (`PROMPTS.md`) и решением пользователя (`README.md`), ADR-0001. |
| Контрольный лист | `control.png` | Нарезанные объекты набора рядом с фигурой героя в масштабе игры; пользователь одобряет набор по нему. |
| Объект окружения | prop, `src/scenes/locations/props/` | Сцена одного объекта декора: тень `GroundShadow` и спрайт с опорой в начале координат. |
| Стоящий / наземный объект | `z_index` спрайта | Стоящий сортируется по y вместе с персонажами; наземный лежит под ними. |
| Кусок локации | `LocationChunk`, `tools/chunks/` | Квадрат декора (по умолчанию 1200 ед.), собирается из JSON-раскладки; локация раскладывает куски по сетке мира. |
| Локация (вид) | `LocationView` | Сцена оформления: земля `EndlessGround` и куски декора вокруг видимой области. |
| Шаг, фаза, сессия roadmap | — | Единица коммита; этап с согласием пользователя; 1–3 шага подряд в одном запуске агента ([roadmaps/README](roadmaps/README.md)). |
